# Mona's Bookmark Manager Roadmap

A focused roadmap for making saved links easier to organize, manage, and keep safe.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search and filter bookmarks | 🚀 | High |
| Management | Edit a saved bookmark | 🚀 | Medium |
| Organization | Add tags or folders | 🚀 | Medium |
| Portability | Import and export bookmarks | 🚀 | Medium |
| Reliability | Prevent duplicate slugs on re-add | 🐞 | Medium |
| Validation | Reject empty or invalid URLs | 🐞 | High |
| Data safety | Warn about bookmark loss if localStorage is cleared | 🐞 | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a saved bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import & export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- ⚠️ Empty-URL validation — priority: high
- 💾 Losing bookmarks when localStorage is cleared — priority: medium
